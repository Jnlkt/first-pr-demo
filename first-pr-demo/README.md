# first-pr-demo

Ein einfaches Demoprojekt zum Ausprobieren von Pull Requests.

## Was ist ein Pull Request?

Ein Pull Request (PR) ist eine Möglichkeit, Änderungen an einem Projekt vorzuschlagen.
Andere können die Änderungen überprüfen, bevor sie in den Hauptzweig übernommen werden.

## Schritte

1. Fork oder klone das Repository
2. Erstelle einen neuen Branch
3. Mache deine Änderungen
4. Öffne einen Pull Request

## Mitwirken

Verbesserungsvorschläge sind herzlich wilkommen!
